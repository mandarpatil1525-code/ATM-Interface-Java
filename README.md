# ATM Interface (Java Console App)

## Run in VS Code
1. Install JDK 11+ and the "Extension Pack for Java".
2. File > Open Folder > select `ATMInterface`.
3. Open `src/Main.java` and click **Run** above `main`
   (or in terminal: `cd src && javac *.java && java Main`).
